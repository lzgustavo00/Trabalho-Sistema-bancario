# Sistema de Registro e Gestão de Contas Bancárias

## Projeto acadêmico - INF101

Este projeto apresenta a primeira etapa do desenvolvimento de um sistema
simples para registro e gerenciamento de contas bancárias.

O programa foi desenvolvido em C++ e tem como objetivo colocar em prática
os fundamentos da linguagem, utilizando variáveis, estruturas condicionais,
repetição, funções e menu interativo.

---

## 1. Sobre o projeto

O sistema permite realizar operações básicas sobre uma conta bancária.

Nesta primeira etapa, o programa trabalha com **uma única conta**, utilizando
variáveis individuais para armazenar as informações.

As informações armazenadas são:

- Número da conta;
- Nome do titular;
- CPF;
- Tipo da conta;
- Saldo;
- Situação da conta.
